# IP 白名单（示例）

> 用途：`scripts/shared/whitelist.js` 的 `isExternal()` 用它判定告警中的 `sip` 是否属于外部地址。
> 格式：以 `#` 开头的行与空行被忽略；支持单 IP、CIDR、短范围（`1.2.3.0-15`）、完整范围（`A-B`）。
> 本文件只是示例。真实业务白名单属于环境数据，不要提交进仓库：部署时用你的环境清单覆盖同名文件即可，代码读取路径不变。
