# 一、统一命名规范（固定格式）

**agent - 领域英文简写 / 核心功能词**

- 全部小写
- 短、好记、好做仓库名、命令行名
- 与你之前的 **软件规模度量智能体** 保持同风格

# 二、已有的两个智能体（对齐规范）

1. **软件规模度量智能体**

   → **agent-sizemeasure**

   

2. **项目验收智能体**

   → **agent-acceptance**

# 三、未来可直接套用的扩展模板

你以后做任何智能体，都用这个公式：

**agent-[核心功能英文单词 / 简洁组合]**

示例（你后续可能用到）：

- 需求分析智能体 → **agent-requirement**
- 进度跟踪智能体 → **agent-progress**
- 质量管控智能体 → **agent-quality**
- 风险评估智能体 → **agent-risk**
- 成本估算智能体 → **agent-cost**
- 文档生成智能体 → **agent-docgen**
- 代码评审智能体 → **agent-codereview**
