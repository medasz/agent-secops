# 公开化改造清单

本仓当前为私有。公开化（fork 成 public 仓、对外发布）之前按本清单走一遍。表里的规模是 2026-09-15 机械扫描的结果，改造后再跑一次第 4 步复核。

## 先说结论

- 敏感面最大的不是源码，是 `releases/*.zip`：18 个发布包（3.5 MB）全部含包内 `scripts/.env`，部分还含 `.env.prd` / `.env.test`，外加 `references/ipWhite.md` 内网白名单。
- 包用 ZipCrypto 加密，密码硬编码在 `releases/release-maker.sh:21` 和 `ops/secops-cron-deploy/install-cron.sh:43`。仓库一公开，这层加密等于没有。
- 所以 zip 密码公开即失效：门户 token、ES 账号、威胁情报 apiKey 一律按已泄露处理，全部轮换。
- 敏感值躺在 git 历史里（历史版本的包中）。只删当前版本的 zip 不够，必须弃历史或用 filter-repo 剔除。

## 待清洗的面

| 面 | 规模 | 处理方式 |
| --- | --- | --- |
| `releases/*.zip` | 18 个包 / 3.5 MB，均含 `.env` + `ipWhite.md` | 公开仓不带包；历史里剔除或新仓弃历史 |
| 硬编码 zip 密码 | 2 处（`release-maker.sh`、`install-cron.sh`） | 改环境变量注入，并轮换密码 |
| 包内凭据 | 门户发布 token、ES 账号、威胁情报 apiKey、代理账号 | 全部轮换；包内改放 `.env.template` |
| 内网地址 | 320 处 / 106 个文件（tests 132、skills 52、archived-openspec 50、specs 50、docs 35） | 换示例网段或脱敏 |
| 内网拓扑清单 | `skills/secops-alert-analysis/references/` 下 `ipWhite.md`、`ipInfra.md`、`MCP-ES-index-logfmt_746_Ref.md` | 换成示例，真实清单外置为运行期配置 |
| 设计文档 | `docs/superpowers/**`、`specs/**`、`archived-openspec/**` | 内网地址与主机名脱敏，必要时整目录不带 |

凭据类字样另有 13 个文件命中，抽样看过多为 JSDoc 类型声明（`@returns {{ token: string …}}`），真值集中在 `.env` 与两处硬编码密码，不是 13 处各自要改。

## 步骤

1. 公开仓怎么建

   不要直接 fork，fork 会把全部历史一起搬过去。两条路：

   - 干净做法：新仓 + `git archive` 导出、单次提交（历史为零，最省事）。
   - 要留历史：`git filter-repo --invert-paths --path releases/` 之后再做公开，并用 `git log --diff-filter=A -- '*.zip'` 复核历史里的包清干净了。

2. 轮换凭据（顺序别反，先换后公开）

   - 门户发布 token、ES 读写账号、威胁情报 apiKey、内网代理账号、zip 包密码。
   - zip 密码两处同步改：`releases/release-maker.sh`、`ops/secops-cron-deploy/install-cron.sh`。

3. 内容改造

   - `.env` → `.env.template`：只留键名和说明，值运行期注入；部署文档改成先填 template。
   - `ipWhite.md`、`ipInfra.md` 的真实内网清单换成示例段，真实清单外置。
   - 测试 fixture 里的内网地址换 RFC 5737 示例段（`192.0.2.0/24`、`198.51.100.0/24`、`203.0.113.0/24`）。
   - `docs/**`、`specs/**` 里的内网地址与主机名脱敏。

4. 发布前复扫（期望全为 0，或只剩示例段）

   ```bash
   git ls-files '*.zip' | wc -l
   grep -rn 'ZIP_PASSWORD=\|SECOPS_ZIP_PASSWORD=' --include='*.sh' .
   git grep -IlE '10\.[0-9]+\.[0-9]+\.[0-9]+|192\.168\.|172\.(1[6-9]|2[0-9]|3[01])\.' | wc -l
   git grep -IlE '(token|secret|password|api[_-]?key)[[:space:]]*[:=][[:space:]]*[^[:space:]]{8,}' -- '*.js' '*.json'
   ```

5. 公开前删掉本清单。
